# 3D Gerald

The 3D-printed case that holds Gerald's Raspberry Pi Zero W, microphone and LEDs.

- `Goose 2 proto.blend`: the Blender source file (editable)
- `Goose 2 proto v1.8.stl`: the printable version

Gerald was modeled in Blender as an organic goose shape with an opening mechanism for the electronics and a mic hole at the front. To print your own, use the `.stl`; to change the design, open the `.blend`.
